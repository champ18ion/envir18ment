  # Free tier infra, targeting ~100 real users initially
  # Single Postgres instance (existing, on Coolify)
  # Must be open source — trust model depends on auditable code
  # Node 22 — libsodium-wrappers ESM broken, using tweetnacl instead

  entry: apps/api/src/index.ts
  pattern: new routes go in apps/api/src/routes/, shared code in packages/

decisions:
  2026-05-27: E2E zero-knowledge encryption — tweetnacl (NaCl box/secretbox) + argon2id — server never sees plaintext
  2026-05-27: argon2id for key derivation from password — OWASP recommended, memory-hard
  2026-05-27: PostgreSQL over SQLite — user already has Postgres running on Coolify, no extra cost
  2026-05-27: @neondatabase/serverless over pg — faster cold connections on Neon
  2026-05-27: Drizzle over Prisma — lighter, no binary, better multi-DB support for future self-hosted SQLite option
  2026-05-27: pnpm workspaces monorepo — apps/api, apps/web, apps/cli share packages/crypto, packages/db, packages/types
  2026-05-27: CLI binary named e18
  2026-05-27: ON DELETE CASCADE on all foreign keys in schema
  2026-05-27: Neon dev branch for local dev, main branch for prod
  2026-05-27: tweetnacl chosen over libsodium-wrappers (broken ESM on Node 22) and over pure Node crypto (weaker primitives)
